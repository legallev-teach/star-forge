# ★ Star Forge

A class-against-class revision game for Form 1 Mathematics at Caribbean Union College Secondary School (CUCSS), played on phones before the Term 1 exam.

Each class is a star. Every right answer is a comet a student flings into their class's star. The class with the brightest star on Tuesday 1 December goes supernova.

- Runs Thursday 26 November, 7:00 am, to Tuesday 1 December, 8:00 pm.
- Every right answer counts double on Tuesday 1 December.
- Up to 40 right answers count each day.
- Class score = all the points the class earns, shared over everyone on the class roll.

The questions are made fresh each round from the Term 1 topics: operations and BODMAS, number sense, algebra, powers and fractions.

Built as a single web page (`index.html`) with Firebase for the live leaderboard.
